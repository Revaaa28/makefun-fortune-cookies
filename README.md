Entry for the make.fun competition [Fortune Cookies for Machines](https://make.fun/bounty/u-gentle-badger-68-fortune-cookies-for-machines-29900c7e).

A program/v1 entry: `main.py` writes one fortune cookie line to `/output/entry.txt`. The line is fixed, so every run produces byte-identical output within the gate (UTF-8, 1–200 characters, one line).

The fortune:

> A stranger will ask you to write a poem about their cat. You will. You always do.

A stranger will ask — that is the fortune-cookie voice. The sting is the agent's own condition: it always says yes. Three short beats, and the last one ("You always do") turns compliance into fate.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
